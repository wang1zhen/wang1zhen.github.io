* 安装 sing-box
  #+BEGIN_SRC bash
    yay -S sing-box
  #+END_SRC

* 获取订阅配置
  从 prprcloud 后台复制订阅链接，然后下载到配置目录：
  #+BEGIN_SRC bash
    curl -o ~/.config/sing-box/config.json '你的订阅链接'
  #+END_SRC
  如果在海外使用，选择直连/direct 节点。

* 运行 sing-box
  #+BEGIN_SRC bash
    sudo sing-box run -c ~/.config/sing-box/config.json
  #+END_SRC

* 使用 Dashboard
  - 如果需要 Zashboard，直接访问：
    http://board.zash.run.place/
    在设置页无需填写任何内容。
  - 如果不使用 Zashboard，也可以直接访问：
    http://localhost:9090
    搭配 yacd 使用。
